## How Attune starts work

Attune keeps configured metadata separate from the records created while work runs. Sensors, triggers, rules, actions, and queue definitions are configuration. Events, enforcements, queue items, and executions record runtime activity.

On the event path, a sensor emits an event for a trigger. Attune checks the event against rules for that trigger. Only matching rule conditions create an enforcement. The rule selects the action, and the enforcement creates an execution of that action. If nothing matches, the event remains recorded and no enforcement is created.

An enforcement records that a rule fired. It does not mean the action succeeded. The execution status and result record the outcome.

For work that must wait for dispatch capacity, producers can submit durable queue items. The queue definition names the dispatch action and controls batching and concurrency. The dispatcher leases one item or a batch, then creates a normal execution of that action. Several items can therefore share one execution, and a retried item can produce another execution.
